# Sprint_6

Автотесты для учебного сервиса «Яндекс.Самокат» на Selenium. 

Тесты проверяют выпадающий список в разделе «Вопросы о важном», полный позитивный сценарий заказа самоката с двумя точками входа и двумя наборами данных, а также навигацию по логотипам «Самокат» и «Яндекс».

Каждый тест полностью автономен: открывает браузер Firefox, выполняет сценарий и закрывает его командой `driver.quit()`. Проект построен на Page Object Model, используется параметризация Pytest, подключён Allure для отчёта.

## Тестовый стенд
https://qa-scooter.praktikum-services.ru/

## Стек
- Python 3.14
- Selenium 4.48
- Pytest 8.2
- Allure-pytest 2.13
- Mozilla Firefox

## Структура файлов

- `conftest.py` — фикстура драйвера Firefox.
- `data.py` — тестовые данные для оформления заказа (два набора).
- `pytest.ini` — конфигурация Pytest (pythonpath, testpaths).
- `requirements.txt` — зависимости проекта.
- `.gitignore` — исключения Git.

### Директория `locators/`
- `main_page_locators.py` — локаторы главной страницы.
- `order_page_locators.py` — локаторы страницы заказа.

### Директория `pages/` (Page Object)
- `base_page.py` — базовые методы (find, click, send_keys, wait).
- `main_page.py` — главная страница: кнопки «Заказать», логотипы, FAQ.
- `order_page.py` — страница заказа: две формы, подтверждение, модальное окно успеха.

### Директория `tests/` содержит файлы со всеми тестами:
- `test_faq.py` — Выпадающий список «Вопросы о важном» (8 параметризованных тестов).
- `test_order.py` — Оформление заказа (позитивный сценарий, 2 набора данных × 2 точки входа) и переходы по логотипам «Самокат» и «Яндекс».
